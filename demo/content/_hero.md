## marmite-feeds

Community feeds widget for Marmite static sites.
**Zero dependencies · Lazy loaded · sessionStorage cache · Fully i18n**

Add live feeds from Hacker News, TabNews, DEV.to, GitHub or any custom JSON API
to your Marmite blog — without modifying any template.

**Sources:** 🟠 Hacker News · 🟣 TabNews · 🔵 DEV.to · ⚫ GitHub · ✦ Custom fetcher
